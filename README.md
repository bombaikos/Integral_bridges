# Puentes integrales

Conocimiento y herramientas para el proyecto de puentes integrales, a partir de la tesis de D. Dreier,
*Interaction sol-structure dans le domaine des ponts intégraux* (EPFL nº 4880, 2010).

| Figuras comentadas: losa de transición y rótula de hormigón | [tesis/losa_transicion_y_rotula.html](tesis/losa_transicion_y_rotula.html) |
| Resumen de la tesis en español | [tesis/resumen_tesis_Dreier_4880.md](tesis/resumen_tesis_Dreier_4880.md) |
| Tesis original (francés) | [EPFL_TH4880.pdf](EPFL_TH4880.pdf) |
